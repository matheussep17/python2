# Site da Igreja

Primeira versão do site institucional, painel administrativo e biblioteca de mídia.

## Rodar localmente

Abra `index.html` no navegador ou sirva a pasta com qualquer servidor estático.
O painel está em `admin.html`.

Esta versão usa `localStorage` apenas como protótipo local. Antes de publicar,
o painel deve receber autenticação e persistência em banco/Storage.
